# مخفی‌سازی و نمایش آیکون Learn about this picture در دسکتاپ ویندوز

قابلیت Windows Spotlight تصاویر و والپیپرهای باکیفیت و متغیری را روزانه روی پس‌زمینه دسکتاپ قرار می‌دهد. با این حال، در آپدیت‌های جدید ویندوز ۱۰ و ۱۱ یک آیکون دائمی به نام **"Learn about this picture"** به دسکتاپ اضافه می‌شود که نمی‌توان آن را به روش معمولی حذف کرد.

این پروژه شامل دو فایل رجیستری ساده (`.reg`) است که به شما امکان می‌دهد این آیکون مزاحم را تنها با یک کلیک مخفی کنید، بدون اینکه والپیپرهای پویای ویندوز غیرفعال شوند.

---

## 📁 فایل‌های موجود در پروژه

| نام فایل | مقدار در رجیستری | عملکرد |
| :--- | :--- | :--- |
| **`Hide Learn about this picture.reg`** | `dword:00000001` | مخفی کردن آیکون از روی دسکتاپ. |
| **`Show Learn about this picture.reg`** | `dword:00000000` | بازگرداندن و نمایش مجدد آیکون روی دسکتاپ. |

---

## ✨ قابلیت‌ها و ویژگی‌ها

* 🖼️ **حفظ والپیپرهای پویا:** تنها آیکون اضافی از روی دسکتاپ برداشته می‌شود و چرخش روزانه تصاویر Spotlight دست‌نخورده باقی می‌ماند.
* ⚡ **اعمال سریع و بومی:** استفاده مستقیم از کلید رسمی رجیستری ویندوز بدون ایجاد اختلال در سیستم.
* 🚫 **بدون نرم‌افزار جانبی:** بدون نیاز به نصب هرگونه برنامه اضافی یا مصرف حافظه رم در پس‌زمینه.
* 🔄 **کاملاً برگشت‌پذیر:** هر زمان که اراده کنید می‌توانید با فایل دیگر، آیکون را به حالت اول بازگردانید.
* 👤 **محدوده سطح کاربر:** تغییرات درون شاخه `HKEY_CURRENT_USER` اعمال می‌شوند و ساختار کلی ویندوز دستکاری نمی‌شود.

---

## 🚀 راهنمای استفاده

1. فایل‌های مخزن را دانلود کنید.
2. بسته به نیاز خود:
   * برای **مخفی کردن** آیکون: روی فایل **`Hide Learn about this picture.reg`** دو بار کلیک کنید.
   * برای **نمایش مجدد** آیکون: روی فایل **`Show Learn about this picture.reg`** دو بار کلیک کنید.
3. در پنجره بازشده، پیام تأیید ویرایشگر رجیستری را با زدن **Yes** تأیید کنید.
4. روی فضای خالی دسکتاپ راست‌کلیک کرده و گزینه **Refresh** را بزنید (یا کلید **F5** کیبورد را بفشارید) تا آیکون بلافاصله مخفی/نمایان شود.

---

## 💻 پیش‌نیازهای سیستم

* **سیستم‌عامل:** ویندوز 10 یا ویندوز 11 (با قابلیت فعال بودن Windows Spotlight).
